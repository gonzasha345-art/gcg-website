# Gonzales Construction Group LLC Website

This project is a Create React App website for Gonzales Construction Group LLC. It includes routed pages for Home, Services, Best Practices, and Contact, along with responsive styling and placeholder brand assets.

## Available Scripts

In the project directory, you can run:

### `npm install`

Installs the project dependencies.

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm test`

Launches the test runner.

### `npm run build`

Builds the app for production to the `build` folder.

## Project Structure

- `src/components/` shared layout and service card components
- `src/pages/` routed page content
- `src/styles/` page and component styles
- `public/assets/` placeholder logo and illustration assets

## Customization Notes

Before launch, replace the placeholder contact details and public assets with the company's final phone number, email, service area, and photography.
